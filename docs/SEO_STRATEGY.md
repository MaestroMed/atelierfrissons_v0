## 0. PRINCIPE DIRECTEUR

Google traite le secteur adult/sexual wellness comme du **YMYL**, au même niveau que le médical, le juridique ou le financier. Ça signifie :

1. Les critères **E-E-A-T** (Experience, Expertise, Authoritativeness, Trustworthiness) sont appliqués avec sévérité
2. Le moindre signal de "spam", "affiliation", "contenu pauvre" entraîne un déclassement durable
3. Les backlinks de mauvaise qualité font **plus de mal que de bien**
4. L'algorithme récompense les sites qui ressemblent à **Mayo Clinic, NHS, HAS, Planned Parenthood**

**Notre stratégie** : faire en sorte que Google classe Atelier Frisson dans la même catégorie que **Typology, Aesop, Smile Makers**, pas dans celle des sexshops.

## 10. TECHNIQUE SEO (ON-PAGE)

### 10.1 Sitemap dynamique

```ts
// app/sitemap.ts
export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const products = await getAllActiveProducts();
  const articles = await getAllPublishedArticles();
  const guides = await getAllPublishedGuides();
  const categories = await getAllCategories();
  const forgePages = await getAllPublishedForgePages();

  return [
    { url: 'https://atelierfrisson.fr', priority: 1.0, changeFrequency: 'daily' },
    { url: 'https://atelierfrisson.fr/boutique', priority: 0.9, changeFrequency: 'daily' },
    // ...
    ...products.map(p => ({
      url: `https://atelierfrisson.fr/produit/${p.slug}`,
      lastModified: p.updatedAt,
      priority: 0.8,
      changeFrequency: 'weekly',
      images: p.images.map(img => img.url),
    })),
    ...articles.map(a => ({
      url: `https://atelierfrisson.fr/rituels/${a.slug}`,
      lastModified: a.updatedAt,
      priority: 0.7,
      changeFrequency: 'monthly',
    })),
    ...guides.map(g => ({
      url: `https://atelierfrisson.fr/guides/${g.slug}`,
      lastModified: g.updatedAt,
      priority: 0.9,
      changeFrequency: 'monthly',
    })),
    ...forgePages.map(f => ({
      url: `https://atelierfrisson.fr/${f.slug}`,
      lastModified: f.updatedAt,
      priority: 0.5,
      changeFrequency: 'monthly',
    })),
  ];
}
```

### 10.2 Robots.txt

```ts
// app/robots.ts
export default function robots(): MetadataRoute.Robots {
  return {
    rules: [
      {
        userAgent: '*',
        allow: '/',
        disallow: [
          '/api/', '/admin/', '/compte/', '/auth/',
          '/checkout/', '/panier', '/_next/', '/search?',
        ],
      },
      { userAgent: 'GPTBot', disallow: '/' },
      { userAgent: 'CCBot', disallow: '/' },
    ],
    sitemap: 'https://atelierfrisson.fr/sitemap.xml',
    host: 'https://atelierfrisson.fr',
  };
}
```
